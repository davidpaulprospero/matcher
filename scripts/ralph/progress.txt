## Iteration 16 - US-002: Add progressive backoff before cookie rotation
- Focus: rate-limiting
- Status: COMPLETE

### Changes Made
Implemented progressive backoff delay before escalating to cookie rotation on rate limit errors.

**Config additions (src/config/sections/download.py):**
- New `RateLimitConfig` dataclass with:
  - `initial_backoff_seconds: float = 5.0` - Initial delay on first rate limit
  - `max_backoff_before_rotate: float = 60.0` - Max cumulative delay before rotation
  - `backoff_multiplier: float = 2.0` - Exponential growth factor
- Added `rate_limit: RateLimitConfig` field to `DownloadConfig`
- Added `__post_init__` handling for dict-to-dataclass conversion

**Config additions (config.yaml):**
- New `download.rate_limit` section with all three settings
- Documented backoff sequence example in comments

**Core implementation (src/downloader/core.py):**
- Added tracking state: `_rate_limit_backoff_count` and `_rate_limit_total_delay`
- Modified `handle_rate_limit_error()` to apply progressive backoff BEFORE rotation:
  1. On rate limit, calculate delay: `initial_backoff * (multiplier ^ count)`
  2. Cap delay so total doesn't exceed `max_backoff_before_rotate`
  3. Sleep and increment counters
  4. After max delay reached, reset counters and escalate to cookie rotation
- Added `_reset_rate_limit_backoff()` method
- Reset backoff on successful download (after videos found)
- Comprehensive logging of backoff progress (attempt #, delay, total/max)

**Backoff sequence with defaults:**
```
1st rate limit: wait 5s (total: 5s)
2nd rate limit: wait 10s (total: 15s)
3rd rate limit: wait 20s (total: 35s)
4th rate limit: wait 25s (total: 60s) -> rotate cookie
```

## Iteration 9 - US-009: Implement caption timestamp normalization
- Focus: caption
- Status: COMPLETE

### Changes Made

Created comprehensive caption timestamp normalization system with CaptionNormalizer class.

**New Classes:**
1. **NormalizationConfig dataclass** - Configurable normalization settings:
   - `overlap_strategy`: 'merge' | 'split' | 'truncate' (default: 'truncate')
   - `gap_strategy`: 'extend' | 'placeholder' | 'ignore' (default: 'ignore')
   - `max_gap_to_extend`: Maximum gap size to extend (default: 1.0s)
   - `min_segment_duration`: Minimum valid segment duration (default: 0.1s)
   - `validate_timestamps`: Whether to validate/fix timestamps (default: True)

2. **CaptionNormalizer class** - Main normalization engine:
   - `normalize(segments, video_id)`: Full normalization pipeline
   - `validate_continuity(segments)`: Validate segment timing, return warnings
   - `convert_timestamp_to_seconds(timestamp)`: Static method for VTT/SRT/JSON3 parsing
   - `seconds_to_vtt_timestamp(seconds)`: Convert seconds to VTT format
   - `seconds_to_srt_timestamp(seconds)`: Convert seconds to SRT format

3. **CaptionNormalizationError exception** - For normalization failures

**Normalization Steps:**
1. Validate individual segment timestamps (fix negatives, extend short durations)
2. Sort segments by start_time
3. Handle overlapping segments based on strategy
4. Handle gaps between segments based on strategy
5. Re-index segments sequentially

**Overlap Strategies:**
- `merge`: Combine overlapping segments into one (concatenate text)
- `split`: Divide at midpoint of overlap
- `truncate`: Trim earlier segment's end to later's start

**Gap Strategies:**
- `extend`: Extend previous segment's end (up to max_gap_to_extend)
- `placeholder`: Insert empty placeholder segments
- `ignore`: Leave gaps as-is (default)

**Validation Fixes:**
- Negative start_time → 0.0
- Negative end_time → segment removed
- end <= start → extend end by min_segment_duration
- Short duration → extend to min_segment_duration
- Empty/whitespace text → segment removed
- Missing source_file → set from video_id
