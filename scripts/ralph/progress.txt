## Operational Notes

### Project Conventions (from CLAUDE.md)
- Config changes: update BOTH src/config.py AND config.yaml
- LLM calls: use src/llm_client/ only
- Tests: use --non-interactive flag
- Dataclass imports: from src/state.py or src/config.py

### Common Gotchas
- Caption-first mode: video_path contains video IDs, not file paths
- Embeddings: use is_embeddings_empty() - numpy fails bool()
- Windows paths: use forward slashes, file:/// URLs
- Project config: use project_config.yaml, not config.yaml for project-specific

### Useful Commands
- Quick test: pytest tests/ -v --tb=short -x
- Sanity check: python main.py --help
- Check stage: checkpoint.json -> last_completed_stage
