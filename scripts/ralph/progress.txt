## Iteration 9 - US-009: Implement caption timestamp normalization
- Focus: caption
- Status: COMPLETE

### Changes Made

Created comprehensive caption timestamp normalization system with CaptionNormalizer class.

**New Classes:**
1. **NormalizationConfig dataclass** - Configurable normalization settings:
   - `overlap_strategy`: 'merge' | 'split' | 'truncate' (default: 'truncate')
   - `gap_strategy`: 'extend' | 'placeholder' | 'ignore' (default: 'ignore')
   - `max_gap_to_extend`: Maximum gap size to extend (default: 1.0s)
   - `min_segment_duration`: Minimum valid segment duration (default: 0.1s)
   - `validate_timestamps`: Whether to validate/fix timestamps (default: True)

2. **CaptionNormalizer class** - Main normalization engine:
   - `normalize(segments, video_id)`: Full normalization pipeline
   - `validate_continuity(segments)`: Validate segment timing, return warnings
   - `convert_timestamp_to_seconds(timestamp)`: Static method for VTT/SRT/JSON3 parsing
   - `seconds_to_vtt_timestamp(seconds)`: Convert seconds to VTT format
   - `seconds_to_srt_timestamp(seconds)`: Convert seconds to SRT format

3. **CaptionNormalizationError exception** - For normalization failures

**Normalization Steps:**
1. Validate individual segment timestamps (fix negatives, extend short durations)
2. Sort segments by start_time
3. Handle overlapping segments based on strategy
4. Handle gaps between segments based on strategy
5. Re-index segments sequentially

**Overlap Strategies:**
- `merge`: Combine overlapping segments into one (concatenate text)
- `split`: Divide at midpoint of overlap
- `truncate`: Trim earlier segment's end to later's start

**Gap Strategies:**
- `extend`: Extend previous segment's end (up to max_gap_to_extend)
- `placeholder`: Insert empty placeholder segments
- `ignore`: Leave gaps as-is (default)

**Validation Fixes:**
- Negative start_time → 0.0
- Negative end_time → segment removed
- end <= start → extend end by min_segment_duration
- Short duration → extend to min_segment_duration
- Empty/whitespace text → segment removed
- Missing source_file → set from video_id

4. **CaptionMetrics tracking**:
   - record_error_category() method (thread-safe)
   - get_error_category_summary() returns counts, rates, top_category

5. **Updated _with_retry() method**:
   - Uses category-specific budgets instead of global max_retries
   - Logs category with retry decision: "NETWORK error, retry 2/3"
   - RATE_LIMIT errors get doubled backoff

NETWORK error, retry 2/3. Waiting 4.0s...

## Iteration - US-006: Create sophisticated segment quality scoring heuristics
- Focus: caption
- Status: COMPLETE

### Changes Made
Added sophisticated segment quality scoring to replace the simplistic low/medium/high classification.

**SegmentQualityMetrics dataclass** (src/caption_fetcher.py:114-166):
- density_score: Segments per minute normalized to 0-1 (optimal ~12/min)
- timing_precision: Percentage with exact millisecond timestamps (0-1)
- text_completeness: Average chars per segment vs expected 50-200 (0-1)
- quality_score: Combined weighted score (0.4*density + 0.3*precision + 0.3*completeness)
- Includes to_dict() and from_dict() methods for serialization

**calculate_segment_metrics() function** (src/caption_fetcher.py:169-312):
- Density score: Bell curve centered at 12 segments/minute (optimal for human captions)
- Timing precision: Detects sub-100ms timestamp precision (auto-generated pattern)
  - Human captions often use round numbers (1.0, 5.0, 10.0)
  - Auto-captions have precise timestamps (1.234, 2.891)
- Text completeness: Scores 1.0 for 50-200 chars/segment average
  - Too short (<50 avg): Truncated or single-word segments
  - Too long (>200 avg): May indicate missed segment breaks
- Handles edge cases: empty segments, auto-calculated duration

### Key Design Decisions
1. **Density optimal at 12/min**: Based on typical human caption timing patterns
2. **Precision quality inverted**: Lower millisecond precision (round numbers) indicates human curation
3. **Weights 0.4/0.3/0.3**: Density weighted highest as it's the strongest quality indicator
